# 芽团 · 桌边的陪伴

原生 HTML / CSS / JavaScript 界面，加上仅在电脑本机运行的 Node.js AI 代理，无第三方安装依赖。静态界面仍可部署至私有站点；真实硬件演示推荐使用本机服务。

## 启动

需要 Node.js 20 或更高版本。在本目录的 `.env` 文件填写 DeepSeek Key（模板为 `.env.example`），然后：

```sh
npm run dev
```

打开 http://127.0.0.1:4173 。浏览器需要通过 HTTP/HTTPS 加载，不能直接双击 HTML 使用 ES modules。

详细接线与现场操作说明：[打开 HTML 使用说明](dist/help.html)，也可以在浏览器中打印为 PDF。

## 三种视图

- `/`：手机与电脑自动适配的控制台。陪伴小屋、饮食、成长、回忆、更多陪伴。
- `/mobile.html`：桌面上查看 420px 手机布局的预览框；真实手机直接打开首页即可。
- `/projection.html`：纯黑背景，左上角显示角色、对话与可选状态。右下角可开启实时陪伴和全屏。位置、大小、状态条可在控制台设置。
- `/help.html`：硬件接线、DeepSeek 配置、语音唤醒与 GIF 素材说明。

控制台与投影页使用 BroadcastChannel 和 localStorage storage 事件同步。同一浏览器、同一来源的页面实时联动；手机和电脑两台设备间尚无同步服务，不能跨设备联动。实际演示推荐在同一电脑打开控制台和投影窗口，将投影窗口拖到扩展屏并全屏。

## 演示操作

1. 点“打开桌面投影”，把黑底窗口放到投影屏。
2. 点“演示模式”或“开始演示”。36 秒经过初见、示例餐食、确认食材、互动、花苞、多花绽放。
3. 可点任意步骤跳转、暂停、重播。演示中的餐食与识别结果均为标注的样例。
4. 聊天或记录真实餐食会先暂停演示。点“结束”恢复演示前的状态；已保存的聊天、记忆和餐食不会被删除。
5. 成长花园可预览四阶段、三种花色和一至三朵花。人物或上传形象共享同一互动状态。

## 真实 AI 接入

本机 `.env` 的三项配置：

```dotenv
YATUAN_AI_ENDPOINT=https://api.deepseek.com/chat/completions
YATUAN_AI_MODEL=deepseek-flash
YATUAN_AI_KEY=在本机填入你的DeepSeek密钥
```

重启 `npm run dev` 后打开 http://127.0.0.1:4173 。页面自动检查本机服务，配置完整时使用 `/api/chat/completions`。密钥只在本机 Node 进程中使用，`.env` 被 Git 忽略，静态服务器不对外提供它。页面只监听回环地址，代理拒绝其他网页来源，固定模型和上游接口。

DeepSeek 模型与视觉参数已按 2026-10-17 [官方 Vision 文档](https://api-docs.deepseek.com/guides/vision/)核对；账户模型权限与余额须以真实调用为准。对官方 DeepSeek 请求使用非思考模式，缩短回复等待；实时观察使用 JSON 结果，客户端只接受有限表情与食材字段，不让模型直接设置成长数值。

1. 用同一浏览器、相同网址打开控制台和投影页。
2. 在投影页打开「开始桌边陪伴」，选择 USB 摄像头，点「开始陪伴」并授权。
3. 说“芽团芽团”唤醒，或点「唤醒芽团」。只有唤醒后才会拍摄并发送图片。
4. 自动观察等待上一轮 AI 和朗读完成后，再等待设定间隔；不会积压帧。画面无变化时模型可选择安静；自动播报至少间隔 18 秒，相同文本不重复朗读。
5. 说“暂停观察”关闭摄像头；“继续观察”恢复；“结束陪伴”停止所有采集。说话播放阶段暂不收音，不支持打断。收起面板仍会继续，结束按钮才会停止。

没有 API 配置时不启动实时设备，保留明确标注的本地演示。连接测试只验证文字；视觉效果需用实际餐盘验证。默认语音识别依赖浏览器服务，不是离线唤醒，不能唤醒已关闭的网页或休眠电脑。当前不提供实时音频大模型/全双工 WebRTC。

私有在线站点为静态前端，不包含本机 Node 进程。若要在线使用真实 AI，需另外部署自己的 HTTPS 代理并在设置填写完整接口；不要在 HTTPS 页面里填写本机 HTTP 服务来绕过浏览器限制。双屏投影场景优先使用同一电脑本机服务，不需要跨设备同步。

## 成长与采样

真实餐盘识别结果可触发表情和游戏成长：有较明确食物类别的餐盘最多每 20 分钟获得一次 +3 成长、+2 活力；主动对话最多每分钟 +1 成长、+1 亲密。不按采样帧刷成长，也不把这些数值解释为营养健康评分。不会从照片推断精确热量、油盐或医学结论。

## 数据与素材

聊天、记忆、手动保存的餐食缩略图、角色和偏好在本地浏览器保存。实时采样帧仅用于当次模型请求，不写入本地日记；发送到 AI 服务后的处理以服务方政策为准。图片有格式、文件体积和存储配额限制；清除浏览器数据会清除本地记录。

本版直接使用已获确认的生成图，通过 SVG 视口与轮廓裁切显示角色，未重新请求图像生成。保留原参考图于 `dist/assets/`。原生 SVG/CSS 负责花朵与实时动作，当前不是骨骼动画或上传照片自动建模。之后的 GIF / WebM 动作文件放在 `dist/assets/motions/`，通过 `dist/animations.js` 映射待机、倾听、思考、说话等状态；现在未提供的素材不会请求或加载。

## 验证


测试覆盖本地记忆、输入边界、存储失败、跨标签同步、演示计时/暂停/恢复与单控制者同步。已进行浏览器界面核验：桌面和手机布局、形象切换、偏好聊天、餐食保存、演示跳步、黑底投影同步。新增测试覆盖代理密钥隔离、固定上游、取消、USB 设备选择、语音恢复、设备互斥、串行采样、播报与成长节流，以及 Chrome 计时器调用、启动失败清理和语音失败后的手动交互。自动测试使用假的模型和媒体设备。本轮 Chrome 排查已确认真实文字连接成功、摄像头启动检查通过；浏览器语音识别出现启动超时，语音对话及实际餐盘识别仍需继续验收。

# bySide 桌边陪伴基座

本机单用户陪伴原型。后端使用 NestJS、Prisma、SQLite，前端使用 React 和 Vite。聊天、记忆、角色和成长保存在本机数据库，投影窗口通过事件流更新。

## 启动

需要 Node.js 22.12 或更高版本。

```sh
npm install
cp .env.example .env
npm run db:setup
npm run build
npm start
```

打开 http://127.0.0.1:4173 使用原版陪伴界面，API 文档在 http://127.0.0.1:4173/api/docs。开发模式运行 `npm run dev`。此前重建的界面仍可通过 http://127.0.0.1:4173/foundation 打开。数据库在 `server/prisma/byside.db`，上传的形象在 `data/uploads/`。

在 `.env` 填写 Chat Completions 兼容服务的完整地址、模型名称和密钥。没有密钥时显示演示回复。视觉模型必须支持图片输入。填写 `VOLC_SPEECH_API_KEY` 可使用豆包流式语音识别和语音合成；开通端到端实时语音后，可用同一密钥或单独配置 `VOLC_REALTIME_API_KEY`。原有 `YATUAN_TTS_KEY` 仍可单独用于语音合成。

图片识别可以在 `.env` 中用 `YATUAN_VISION_MODEL` 指定独立模型 ID，留空时使用 `YATUAN_AI_MODEL`；两者共用上述模型服务地址和密钥。

`YATUAN_AI_THINKING` 控制兼容服务的思考参数：默认 `auto` 对 DeepSeek 模型请求关闭思考，其他模型不额外发送该参数；可设为 `enabled` 或 `disabled`。非 DeepSeek 或第三方兼容服务需自行确认支持此参数。修改后重启基座生效；它不改变豆包实时语音模型的设置。

原界面的摄像头与麦克风由浏览器请求权限。“开始陪伴”使用豆包端到端实时语音，同时默认每 10 秒采样桌面图片，并按问题请求新画面。图片分析期间语音继续传输。暂停观察后可继续说话，结束陪伴会释放本轮采集资源。AR 已开启时复用其摄像头画面。普通语音输入按钮继续支持豆包分段识别及浏览器识别回退。

也可以在基座运行时通过 `npm run voice:native` 单独启动本机音频进程，关闭浏览器后仍可实时对话；它默认使用 macOS 的系统音频设备，也支持接入其他平台的设备适配器。具体用法和设备协议见 [音频设备接入](docs/音频设备接入.md)。

## API 与扩展

基础 API 位于 `/api/v1`。`GET /snapshot` 获取当前状态，`GET /events?after=<id>` 接收 SSE 事件，`POST /chat` 发送消息，`POST /vision` 分析图片，`POST /speech` 合成语音。其他接口及参数见 API 文档。客户端封装在 `sdk/client.ts`。

使用 `POST /extensions` 注册本机扩展，返回的令牌仅显示一次。权限包括 `read`、`growth` 和 `respond`。扩展使用 Bearer 令牌调用对应接口，通过 `eventId` 去重成长事件。支持声明动作和订阅事件；扩展可按事件 ID 续传。完整步骤、权限边界、豆包语音配置和可运行示例见 [能力接入指南](docs/能力接入指南.md)。

原界面顶部“开始陪伴”支持边语音聊天边看桌面，聊天卡片提供纯语音入口。默认半双工，戴耳机时可开启打断。配置、数据同步、摄像头帧及 WebSocket 协议见 [实时语音接入](docs/实时语音接入.md)。

饮食和五子棋后续通过扩展接入。首期投影和设备在同一台电脑使用。

## 原界面与基座

项目内 `original-ui/` 是从旧仓库复制并适配的前端。聊天、记忆、角色、成长数值和投影设置与本机基座同步，控制页和投影页使用同一份服务端状态。成长演示与阶段预览是临时画面。餐食记录和五子棋仍使用原前端的本地逻辑，尚未接入基座扩展接口。

实时陪伴的桌面观察返回描述、食物与饮品类别及识别确定性，通过内置 `observe_desktop` 工具提供给豆包。图片采样本身不增加成长，聊天使用基座现有的成长规则。实际餐盘识别效果需结合取景、光线及设备确认。

## 桌面 AR 预览

打开原版界面，点击“开始投影”会直接进入桌面 AR 预览并尝试连接上次使用的手机摄像头，无线和 USB 连续互通相机均可使用。若手机暂未上线，页面会等待设备出现后尝试连接。首次没有记住手机或未显示设备名称时，点击“授权识别设备”，再选择 iPhone 并连接。先连接 AR 摄像头，再开始陪伴可共享采样画面。

把手机对准桌面：点击“自动识别白纸”可使用完整白纸作为投影面；也可以点“手动圈定”，依次选择完整投影画面的左上、右上、右下、左下四角。如果画面中有可识别且固定在同一平面上的白纸，系统会尝试用它作为参照并保留手动选定的边界；否则需要足够的桌面纹理。跟踪成功后可调整大小。按“关闭摄像头”或“退出 AR”释放摄像头。视频和桌面追踪在浏览器本机处理，不会因为打开此预览而发送至 AI 服务。

白纸短暂被遮挡时，预览会隐藏并在原位置附近寻找；找到符合条件的白纸后会恢复，找不到时请重新识别或圈定。白纸必须与投影区域在同一平面并固定不动。此功能是基于图像特征的平面追踪，不是自动识别桌面或真正的实体投影。纸张边缘不完整、桌面纯色且没有纸张、反光、被遮挡、移出画面，或手机移动太快时可能丢失，界面将提示重新圈定。更换镜头、位置或设备后应重新标定。角色、对话和状态仍沿用原版投影页的同步机制。

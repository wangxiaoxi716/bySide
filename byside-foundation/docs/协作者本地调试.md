# 芽团协作者本地调试

每位协作者在自己的电脑上运行一套后端和浏览器界面。摄像头、麦克风、校准和 SQLite 数据均使用自己的电脑，不需要连接开发者的 Mac。

## 从 GitHub 获取代码

准备 Git、Node.js 22.12 或更高版本、npm 和桌面 Chrome。在 macOS/Linux 的终端或 Windows PowerShell 执行：

```sh
git clone https://github.com/wangxiaoxi716/bySide.git
cd bySide/byside-foundation
node --version
npm ci
```

已有仓库时，在仓库根目录运行 `git fetch origin`、`git switch main` 和 `git pull --ff-only origin main`，再进入 `byside-foundation`。若有本地改动，先检查并保存自己的工作。

## 配置、初始化与启动

在 `byside-foundation` 中复制配置模板：

- macOS/Linux：`cp .env.example .env`
- Windows PowerShell：`Copy-Item .env.example .env`

没有模型密钥也可以先启动、看界面和调试设备。要验证百炼实时语音和实体落子图片反馈，在本机 `.env` 填写：

```dotenv
YATUAN_REALTIME_PROVIDER=bailian
BAILIAN_REALTIME_HOST=填写同一地域的业务空间 API Host
BAILIAN_API_KEY=填写该业务空间的 API Key
```

API Host 只填域名，例如北京地域格式为 `llm-你的业务空间ID.cn-beijing.maas.aliyuncs.com`，不要加协议或路径。实时语音使用 `qwen3.8-omni-flash-realtime`；实体落子后的单图请求使用 `qwen3.8-omni-flash`。基础文字聊天和其它独立视觉页面使用模板里的 `YATUAN_AI_*` 与 `YATUAN_VISION_MODEL`，与棋盘视觉配置分开。不要将 `.env` 或密钥提交到 GitHub。

```sh
npm run db:setup
npm run build
npm start
```

- 主页：[http://127.0.0.1:4173/](http://127.0.0.1:4173/)
- 投影调试：[http://127.0.0.1:4173/projection.html](http://127.0.0.1:4173/projection.html)
- [健康检查](http://127.0.0.1:4173/api/v1/health) · [API 文档](http://127.0.0.1:4173/api/docs)

保持启动终端运行，`Ctrl+C` 停止。改 `.env` 后重启。开发后端时可运行 `npm run dev`；修改 `original-ui/` 后刷新页面即可。不要同时运行两个监听 4173 的实例。

## 按顺序调试

1. **语音。** 在投影调试页点击「开始实时语音」，授权麦克风，说「你好，芽团」，确认同时有文字和语音回应。若一直在听，检查操作系统和 Chrome 的默认麦克风、权限与页面提示。该按钮走纯音频，摄像头未连接也可以单独测试。
2. **摄像头。** 在 AR 预览选择实际连接的摄像头，确认桌面清晰可见。切到黑背景后会复用摄像头；下次尝试自动连接记住的设备。
3. **纯投影与跟随。** 点「打开纯投影输出」，把输出窗拖到投影仪扩展屏，双击或按 F 全屏。调试窗留在电脑屏幕，点「校准角色跟随」。保证四个光点都落在摄像头能看到的桌面上，校准期间不要移动设备或物品。标志物可先用[标准 ArUco 打印图](../original-ui/assets/yatuan-aruco-4x4-50-id0.svg)。设备、窗口位置或尺寸变化后重新校准。
4. **实体棋盘。** 在调试端开启语音，说「开始井字棋」或「开始五子棋」。把一颗黑棋子放到空格中央或交叉点，停稳约半秒；等芽团回应后，再移走它开始下一手。程序只在确认落子时上传一张照片；若图片建议无效或超时，由本地规则接着落子。没有实体落子反应时，先看调试端是否在等待校准、棋盘边界或识别黑棋。

快速回归（无需摄像头、麦克风和模型密钥）：

```sh
node --test tests/physical-chess.test.mjs tests/game-ar-projection.test.mjs tests/camera-start.test.mjs tests/plane-tracking.test.mjs
```

完整后端回归用 `npm test`，其中实时 WebSocket 集成测试额外需要 PATH 中能运行 `sqlite3`。浏览器和实体投影的表现仍要在各自设备上验证。排查时记录操作步骤、调试页文字提示及终端错误；分享前删除密钥、私人画面和本机数据。

# 桌面追踪叠加实现计划

目标：在原版投影页中，把伙伴与对话作为平面投影，追踪由用户四点圈定的桌面区域。视频只在本机处理。

1. 建立独立透视几何和设备会话：验证无效四边形、单应变换、权限拒绝、摄像头停止与延迟结果清理。
2. 集成本地 OpenCV.js：桌面特征点跟踪、RANSAC 平面估计、低质量/丢失时隐藏角色并提示重新标定；用合成帧验证平移与丢失。
3. 原版投影页增加摄像头选择、开始/结束、四角标定、位置与大小调整；保持原有投影和状态同步，避免实时陪伴争用摄像头。
4. 实机 Chrome + iPhone 验证设备、画面、位置、角度变化和退出释放；区分合成测试与实际验收。

约束：首次手动标定；不声称任意角度都可追踪；无实体投影；不自动上传视频或启用摄像头；保留原界面。

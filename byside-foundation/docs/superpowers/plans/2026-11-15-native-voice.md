# 本机独立语音设备进程实现计划

**目标：** 浏览器关闭后仍可通过本机麦克风和扬声器与现有陪伴基座实时对话，同时保留页面、投影和现有语音入口。

**架构：** 单独启动的 TypeScript 设备客户端通过已有本机 WebSocket 对接基座；平台无关的 1.0 音频设备协议允许替换适配器，首个适配器使用 macOS 默认输入输出设备。基座继续负责云端连接、消息、记忆、成长和事件同步。默认半双工，音频确实播完后再开放麦克风；明确启动和停止，不自动抢占设备。

**技术：** Node.js、TypeScript、现有 `ws` 依赖、macOS AVFoundation。单机进程不读取语音密钥。
